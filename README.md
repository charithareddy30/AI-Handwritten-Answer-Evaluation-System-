# AI-Based Handwritten Answer Evaluation System

An AI-based system that evaluates handwritten answers by converting handwritten text into digital text and comparing it with the expected answer.

## 📌 Project Overview

The system uses Artificial Intelligence and Natural Language Processing to automatically evaluate handwritten answers.

It first extracts text from a handwritten answer using OCR and then compares the extracted answer with the expected answer using semantic similarity.

## 🎯 Objectives

* Convert handwritten answers into digital text.
* Correct spelling errors in the extracted text.
* Compare student answers with expected answers.
* Calculate a similarity score.
* Reduce manual effort in answer evaluation.

## 🛠️ Technologies Used

* Python
* OpenCV
* Tesseract OCR
* Sentence Transformers
* NLP
* TextBlob

## ⚙️ How It Works

1. Upload a handwritten answer image.
2. OpenCV processes and improves the image.
3. Tesseract OCR extracts the text.
4. TextBlob helps with spelling correction.
5. Sentence Transformer converts the answers into numerical representations.
6. Semantic similarity is calculated between the student answer and expected answer.
7. The system produces a similarity score.

## 🧠 Model

The project uses:

**Sentence Transformer – all-MiniLM-L6-v2**

This model is used to understand the meaning of the student answer and compare it with the expected answer.
